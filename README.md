# All Radio Python

Простой desktop-аналог All Radio на Python: поиск интернет-радиостанций, воспроизведение, громкость и избранное.


## Что умеет

- искать радиостанции через `pyradios`;
- фильтровать по стране и языку/тегу;
- проигрывать поток через VLC/libVLC;
- сохранять избранные станции локально;
- показывать codec, bitrate, страну, язык и голоса станции;
- собираться в `.exe` через PyInstaller.

## Установка на Windows

1. Установи Python 3.11+.
2. Установи VLC Media Player x64: https://www.videolan.org/vlc/
3. Открой терминал в папке проекта.
4. Создай виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate
```

5. Установи зависимости:

```bash
pip install -r requirements.txt
```

6. Запусти приложение:

```bash
python main.py
```

## Сборка в exe

```bash
build_exe.bat
```

Готовый файл появится в папке `dist/AllRadioPython/`.

## Важные замечания

- Если станция не играет, это не всегда ошибка программы: часть потоков у радиостанций может быть мертвой, недоступной из твоего региона или временно лежать.
- Для работы `python-vlc` нужен установленный VLC той же разрядности, что и Python: обычно Python x64 + VLC x64.
- Избранное хранится в `%USERPROFILE%\.all_radio_python\favorites.json`.
