# All Radio Python

Простой desktop-аналог All Radio на Python: поиск интернет-радиостанций, воспроизведение, громкость и избранное.


## Что изменено

- Каталог Radio Browser вынесен в `radio/radio_browser.py`.
- Поиск больше не ограничен JSON: используются JSON, M3U-формат Radio Browser, публичный M3U-плейлист интернет-радио и локальные `.m3u/.m3u8`.
- Свои плейлисты можно положить в папку `playlists/` рядом с программой или в `%USERPROFILE%\.all_radio_python\playlists`.
- В приложении можно нажать `Своя станция`, выбрать локальный плейлист `.m3u`, `.m3u8`, `.pls` или `.xspf` и сохранить его как свою радиостанцию.
- Свои станции хранятся в `%USERPROFILE%\.all_radio_python\custom_stations.json` и добавляются в начало результатов поиска.
- При запуске приложение сразу ищет станции в онлайн-каталогах и плейлистах, без автоматического резервного списка.
- В таблице есть колонка `Страна вещания`: если источник не отдаёт страну, показывается `Не указана`.
- Резервные станции остаются в `radio/fallback.py` как ручной запас для разработки, но не подставляются автоматически при поиске.
- Избранное вынесено в `radio/favorites.py`.
- Единая модель станции находится в `radio/models.py`.
- Добавлены тесты для нормализации, дедупликации, M3U, ошибок онлайн-поиска и избранного.

## Установка

```bash
python -m venv .venv
# linux  or macOS source .venv/bin/activate 
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

6. Запусти приложение:

```bash
python main.py
```

## Тесты

```bash
pytest
```

Готовый файл появится в папке `dist/AllRadioPython/`.

## Важные замечания

- Если станция не играет, это не всегда ошибка программы: часть потоков у радиостанций может быть мертвой, недоступной из твоего региона или временно лежать.
- Для работы `python-vlc` нужен установленный VLC той же разрядности, что и Python: обычно Python x64 + VLC x64.
- Избранное хранится в `%USERPROFILE%\.all_radio_python\favorites.json`.
